# Daily Brief site

Static PWA published via GitHub Pages. See "SETUP - iPhone App.md" in the Dev Tracker folder for one-time install instructions.

Files:
- `index.html` — today's brief (overwritten daily)
- `archive.html` — index of past briefs
- `archive/YYYY-MM-DD.html` — dated snapshots
- `manifest.json`, `icon-180.png`, `icon-192.png`, `icon-512.png` — PWA / Home Screen icon assets
